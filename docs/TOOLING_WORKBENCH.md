# Local integrated tooling workbench

Run `Torn Veil Tooling.cmd` from the authoritative Desktop checkout. The launcher reuses a compatible tooling server or chooses an available loopback port starting at 7486. Existing servers and worlds are preserved.

Tabs share one origin and retain mounted previews: Observatory, Model ontology, Claude action Arena, Tower, Tools & checks. URL hashes support deep links, browser back/forward and refresh. Observatory remains an isolated canonical world. Claude Arena/Tower are browser-only action labs with separate mechanics; pause with P before leaving their tab. Ontology appearance previews never write simulation identity.

The ontology is consumed from the sibling `ontology/dist` build, with assets from its local public directory and explicit reference manifest. Source code is not copied into Torn Veil. `TORN_VEIL_ONTOLOGY_ROOT` can select another authorized local ontology directory. The ontology consumes the existing Claude-authored `src/web/arena/retarget.ts` helper, with rest-direction compensation and hip scaling, for two CC0 UAL motion studies.

Tools exposes fixed typecheck, focused test and build actions. One child task runs at a time, with bounded output and explicit completion. There is no arbitrary shell endpoint, remote launcher, install action, process killer or save mutation. Build availability means a local bundle exists, not that visual art is approved or the build is current. Rebuild after source edits.
