# Web client — source, asset and conversion manifest

Recorded 2026-09-29 on branch `claude/web-rebirth`. Everything in the browser client's visible
content is **procedurally generated by code in this repository**: no third-party model, texture,
font, audio sample or image is bundled. That is the licence audit's whole finding, and it is why
there is nothing to attribute beyond the two open-source runtime libraries below.

## Conversion manifest (source → runtime)

| Stage | Input | Tool | Output |
|---|---|---|---|
| Model build | `art/tools/web_characters/*.py` | Blender 5.2.1 headless, `npm run web:assets` | `web/public/models/*.glb` (git-ignored, reproducible) |
| Bundle | `web/`, `src/web/`, `web/public/` | Vite 5 (`npm run web:build`) | `dist-web/` (git-ignored) |
| Serve | `dist-web/` | `src/webgate/gateway.ts` | `http://127.0.0.1:<port>` only |

Material slots in the GLBs are named by role (`TV_SkinBody`, `TV_SkinHead`, `TV_Eye`, `TV_Hair`,
`TV_Cloth`, `TV_Under`, `TV_Accent`, `TV_Hem`, `TV_Metal`, `TV_Leather`, `TV_Fur`, `TV_Straw`,
`TV_Lacquer`, `TV_Crystal`, …). The client tints them at runtime from the canonical appearance tokens
(`src/web/actors/appearanceMap.ts`); appearance is cosmetic and never feeds back into the
simulation. Parts carry `tv_part` / `tv_garment` / `tv_style` custom properties the client reads.

## Rebuild

```
npm run web:assets            # builds any missing model (finds Blender via $BLENDER or Program Files)
npm run web:assets -- --all   # rebuild every model
npm run web:build             # bundle into dist-web (copies web/public/models)
```

The launcher's preflight stops with this instruction if `dist-web\models\kit_f.glb` is absent. The
GLBs are intentionally not committed (about 19 MB of derived binaries); the scripts are.

## Rules the assets obey

- Missing assets never change the world: a missing model degrades to a labelled placeholder body
  (`placeholderVisual`) and the simulation is unaffected.
- Concept creatures are **previews**: void stag, rift hawk, veil wraith and shattered colossus are
  shown only in the client's preview scene (`?showroom=…`), never spawned as canonical entities.
  Wildlife the simulation actually has (deer, boar, hare) uses its own species models.
- Hero appearance (`heroRealization`) is selectable in the showroom only; it does not alter who the
  server says the player is.
